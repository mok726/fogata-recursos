Historia del Proyecto

Todo comenzó durante mis primeros años como educador en la Manada Scout.

Como muchos dirigentes, empecé documentando actividades en mensajes de texto y documentos sencillos para que el resto del equipo pudiera utilizarlas. Con el tiempo descubrí programas educativos como GoSolar, Campeones por la Naturaleza, Planeta Sano (Plastic Tide Turners) y las insignias de desafío de YUNGA.

Cada uno aportaba materiales excelentes, pero estaban distribuidos en diferentes sitios, formatos y niveles de calidad.

La búsqueda de un formato común

Una de las mayores inspiraciones fueron los Action Kits de scout.org.

Su estructura clara, práctica y orientada a la acción me mostró que era posible presentar una actividad de forma simple sin perder información importante.

A partir de allí comencé a transformar actividades provenientes de múltiples fuentes a un formato común.

De documentos a sitio web

Con los años la colección creció.

Lo que comenzó como documentos aislados terminó convirtiéndose en una base de actividades en Markdown acompañada por herramientas de automatización desarrolladas específicamente para organizar y mantener el contenido.

Más adelante llegaron las herramientas de inteligencia artificial, que ayudaron en tareas de revisión, clasificación y generación de material gráfico para acompañar las actividades.

Publicación

En abril de 2026 el proyecto alcanzó una etapa suficientemente estable para ser publicado como sitio web.

La migración a GitHub permitió simplificar el mantenimiento, automatizar procesos y ofrecer acceso libre al contenido.

Desde entonces el proyecto continúa creciendo y evolucionando.

Una biblioteca en construcción

Fogata de Recursos no pretende ser una colección cerrada.

Es una biblioteca viva que seguirá incorporando nuevas actividades, corrigiendo errores y mejorando su organización con el tiempo.

Si has llegado hasta aquí, gracias por acompañar este recorrido.

Mariano (Kotick)
