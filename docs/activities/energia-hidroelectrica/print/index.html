Energía hidroeléctrica

Construye un molino de agua para entender cómo se genera energía hidroeléctrica.

Desarrollo

Realiza tu propio molino de agua para comprender cómo funcionan las turbinas en las centrales de energía y cómo los antiguos molinos usaban la energía del agua para moler el trigo. Aquí puedes encontrar instrucciones de cómo construir un molino de agua: www.uptoten.com/kids/coloringpage-mixedbag-craft-colorfulwatermillcraft.html (en inglés) o www.tyengineering.org/lang/spanish/lessons/watermills_sp.pdf; http://www.ehowenespanol.com/actividades-hidroelectricas-ninos-info_98668/ (en español).

Cierre

Reflexiona sobre cómo el agua puede ser una fuente de energía sostenible. Preguntas para discutir: ¿Cómo funciona el molino de agua? ¿Qué ventajas tiene la energía hidroeléctrica?
