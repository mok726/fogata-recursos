Encuesta sobre el Suelo

Realiza una encuesta para entender cómo las personas interactúan con el suelo.

Desarrollo

Pregunta a amigos, familiares y profesores sobre su relación con el suelo (jardinería, deportes, etc.). Prepara una exposición con las respuestas.

Cierre

Organiza una 'casa abierta' para presentar los resultados de la encuesta.
