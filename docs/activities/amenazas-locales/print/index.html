Amenazas locales

Identificar y abordar amenazas a polinizadores locales.

Resumen

¿Cuáles son las amenazas para los polinizadores locales? Hacé una lista de los posibles factores. ¿Hay mucha construcción? ¿Hay mucha deforestación para fines agrícolas? Hacé una encuesta comunitaria para saber qué tipos de pesticidas se usan más en tu área. ¿Son dañinos para los polinizadores? ¿Qué pasa con la contaminación? ¿Es un problema en tu región?

Preparación

  1. Investigá las amenazas potenciales para los polinizadores.
  2. Prepará una encuesta comunitaria.
  3. Organizá los grupos de trabajo.

Desarrollo

  1. Identificá las amenazas en tu área.
  2. Realizá una encuesta sobre el uso de pesticidas.
  3. Analizá los resultados.
  4. Elegí la amenaza más importante.
  5. Desarrollá un plan de acción.

Cierre

  1. Compartí tu plan con el grupo.
  2. Trabajen juntos para implementarlo.
  3. Pregunta final: ¿Qué amenaza abordarás primero?
