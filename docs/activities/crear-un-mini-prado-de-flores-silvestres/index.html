Convierte un área de césped en un prado de flores silvestres para los polinizadores.

groups

Desarrollo

  1. Cubre el césped con cartón, plástico o periódico para matar la hierba.
  2. Añade una capa de compost sobre el material.
  3. Después de 6-8 semanas, retira el material y siembra semillas de flores silvestres nativas.
  4. Riega el área regularmente hasta que las flores germinen.
