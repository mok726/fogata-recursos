Adivina el ODS

Resumen

Actividad obligatoria para la categoría: ENERGÍA PARA UN MUNDO MEJOR. Representa un ODS mediante una obra de teatro sin nombrarlo.

Desarrollo

En equipos, creen una obra sobre un ODS (ej: energía limpia) usando solo acciones/diálogos abstractos. Los demás deben adivinarlo.
