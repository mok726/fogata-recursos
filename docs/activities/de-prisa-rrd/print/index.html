¡De Prisa!

Investigación sobre huracanes y su categorización.

Preparación

  1. Investiga las categorías de viento de huracanes.
  2. Busca información sobre el peor huracán registrado.
  3. Prepara materiales para tu presentación.

Desarrollo

  1. Investigación (25 min): Averigua las categorías y cómo se miden.
  2. Análisis (15 min): Investiga el peor huracán registrado y sus daños.
  3. Creación (15 min): Crea una página web o presentación.
  4. Presentación (5 min): Comparte tu trabajo con la clase o familia.

Cierre

  • ¿Cuáles son las categorías de huracanes?
  • ¿Qué daños puede causar cada categoría?
  • ¿Cómo puedes prepararte para un huracán?

Texto original completo de la actividad

A.08 ¡DE PRISA! Los huracanes están categorizados en 5 tipos dependiendo de la velocidad de su viento y su capacidad de causar daños. Averigua cuáles son estas categorías de viento. ¿Cómo las miden los científicos? ¿Cuál fue el peor huracán jamás registrado? ¿Cuál fue la velocidad de sus vientos? ¿Qué tipos de daños causó? ¿Qué puedes hacer para prepararte para un huracán? Crea una página web o una presentación de PowerPoint para exponer tu investigación y compártela con tu clase o familia.
