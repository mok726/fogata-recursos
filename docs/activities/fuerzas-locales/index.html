Fuerzas Locales

Resumen

Contacta a las autoridades ambientales locales para saber qué están haciendo para proteger a los polinizadores.

Desarrollo

  1. Contacta a las autoridades ambientales locales. 2. Pregunta si hay prohibiciones de pesticidas, si los parques tienen flores nativas o si hay leyes que apoyen la apicultura. 3. Si no están haciendo lo suficiente, envía una lista de sugerencias y ofrece trabajar con ellos para organizar una campaña.
