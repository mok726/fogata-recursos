Diseccioná una flor

Diseccionar una flor para aprender sus partes.

Preparación

  1. Conseguí flores de diferentes tamaños y colores.
  2. Prepará papel y lápices para dibujar y tomar notas.
  3. Organizá el espacio de trabajo.

Desarrollo

  1. Arrancá las flores con cuidado.
  2. Separá las partes suavemente.
  3. Compará con el diagrama de la página 33 del libro.
  4. Identificá las diferentes partes.
  5. Dibujá lo que ves y etiquetá las partes.

Cierre

  1. Reflexioná: ¿Dónde se produce el polen? ¿Qué parte recibe el polen para producir semillas?
  2. Compartí tus hallazgos con el grupo.
  3. Pregunta final: ¿Qué flor te pareció más interesante para diseccionar?

Texto original completo de la actividad

English version:

A.03 DISSECT A FLOWER. Get permission to pluck a few flowers for this activity. Try choosing flowers of different sizes and colors. After you pluck them, gently take them apart and examine the different parts. Compare against the diagram on page 33. Do you recognize the different parts? Where is pollen produced and which part receives pollen to produce seeds?

Versión en español:

A.03 Diseccioná una flor

Obtené permiso para arrancar algunas flores para esta actividad. Tratá de elegir flores de diferentes tamaños y colores. Después de arrancarlas, separalas suavemente y examiná las diferentes partes. Compará con el diagrama de la página 33. ¿Reconocés las diferentes partes? ¿Dónde se produce el polen y qué parte recibe el polen para producir semillas?
