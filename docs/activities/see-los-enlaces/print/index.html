S.E.E los enlaces

Conecta sociedad, medio ambiente y economía.

Preparación

  1. Prepara un set de dados de tres colores diferentes.
  2. Define el significado de cada dado (rojo, verde, azul).
  3. Divide a los participantes en grupos pequeños.

Desarrollo

Parte I - Preparación

Permite que los participantes se sienten en pequeños grupos. Uno de los participantes lanza el set de dados. Se escogen tres números, uno de cada dado (rojo, verde y azul). Usa los números para elegir un tema de cada categoría para crear una historia.

Dado rojo - Función del Ecosistema:

  1. Regular el ciclo del agua
  2. Refugio (para animales)
  3. Alimentos (para humanos)
  4. Regular el clima
  5. Filtrar agua y aire
  6. Biodiversidad para la resiliencia

Dado verde - Componente del Ecosistema:

  1. Agua
  2. Aire
  3. Tierra
  4. Nutriente
  5. Vida silvestre
  6. Vegetación

Dado azul - Impacto/uso:

  1. Producción intensiva de alimentos
  2. Generación de energía
  3. Agua potable
  4. Minería
  5. Turismo intenso
  6. Urbanización

Parte II - Crear historia

Se le da unos minutos a cada grupo para discutir y componer una breve historia. Los términos se pueden usar en cualquier orden. El grupo escribe la historia. Cuando la historia está terminada, lancen los dados nuevamente para crear una nueva historia.

Parte III - Compartir

Cuando todos los grupos hayan completado al menos una historia, pide a algunos grupos que la compartan y luego discutan las historias.

Ejemplo: Dado rojo 1 (Regular el Ciclo del agua), dado verde 3 (Tierra), dado azul 2 (Generación de energía) Una ciudad a orillas de un río necesita más electricidad debido al aumento de la población y la industria en la zona. Un río cercano es lo suficientemente grande como para proporcionar toda la energía necesaria, una vez que se coloca en un embalse. El río represado rompe el ciclo natural de diferentes descargas a través del río y reduce el agua promedio en el río. Los peces ya no pueden continuar migrando río arriba para procrearse. Todo el sedimento rico en nutrientes que anteriormente se transportaba a través del río y se depositaba en las orillas del río en la temporada alta de agua, ahora está atrapado detrás de la presa. El ciclo natural/regular del agua se rompe a causa de la presa y el ecosistema río abajo cambia debido a la falta de suelo rico en nutrientes.

Parte IV - Variación (opcional)

Puedes ir más allá agregando un juego adicional de dados; dados personales. Estos dados mostrarán emociones: alegría, tristeza, felicidad, decepción, satisfacción y emoción.

Cierre

  1. ¿Qué historia te pareció más interesante?
  2. ¿Cómo se conectan sociedad, medio ambiente y economía?
  3. ¿Qué aprendiste sobre los ecosistemas?

Título: S.E.E los enlaces

Tiempo: 20 - 30 minutos

Grupo Etario: De 14 años en adelante

Resumen: Explorar los vínculos entre Sociedad, Medio Ambiente y Economía (= S.E.E. por su sigla en inglés) al observar la función de cada ecosistema, los componentes y los posibles impactos en otro.

Recursos y Materiales: Un set de tres dados cada uno con un color diferente y su significado

Competencias clave: Colaboración

Desarrollo de la actividad:

  1. Permite que los participantes se sienten en pequeños grupos. Uno de los participantes lanza el set de dados.
  2. Se escogen tres números, uno de cada dado (rojo, verde y azul). Usa los números para elegir un tema de cada categoría para crear una historia.
  3. Se le da unos minutos a cada grupo para discutir y componer una breve historia. Los términos se pueden usar en cualquier orden. El grupo escribe la historia. Cuando la historia está terminada, lancen los dados nuevamente para crear una nueva historia.
  4. Cuando todos los grupos hayan completado al menos una historia, pide a algunos grupos que la compartan y luego discutan las historias.
  5. Variación: puedes ir más allá agregando un juego adicional de dados; dados personales. Estos dados mostrarán emociones: alegría, tristeza, felicidad, decepción, satisfacción y emoción.

Dado rojo - Función del Ecosistema: 1. Regular el ciclo del agua, 2. Refugio (para animales), 3. Alimentos (para humanos), 4. Regular el clima, 5. Filtrar agua y aire, 6. Biodiversidad para la resiliencia

Dado verde - Componente del Ecosistema: 1. Agua, 2. Aire, 3. Tierra, 4. Nutriente, 5. Vida silvestre, 6. Vegetación

Dado azul - Impacto/uso: 1. Producción intensiva de alimentos, 2. Generación de energía, 3. Agua potable, 4. Minería, 5. Turismo intenso, 6. Urbanización

Ejemplo de historia: Una ciudad a orillas de un río necesita más electricidad debido al aumento de la población y la industria en la zona.
