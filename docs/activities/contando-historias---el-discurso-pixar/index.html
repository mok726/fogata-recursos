Contando historias - El Discurso Pixar

Resumen

Esta actividad permite a los participantes crear historias convincentes para abogar por la biodiversidad utilizando el formato de narrativa de Pixar.

Desarrollo

  1. Los participantes eligen un tema relacionado con la biodiversidad (por ejemplo, pérdida de hábitat, especies en peligro, etc.). 2. Utilizan el formato de narrativa de Pixar (6 frases) para crear una historia. 3. Comparten sus historias con el grupo y reflexionan sobre cómo pueden usarlas para abogar por la biodiversidad.

Cierre

  • Reflexiona sobre cómo las historias pueden inspirar a otros a tomar acción. - Pregunta: ¿Cómo puedes usar tu historia para crear conciencia sobre la biodiversidad?
