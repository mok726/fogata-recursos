Regular el uso de plásticos

Resumen

Actividad que ayuda a los jóvenes a comprender cómo se elaboran las leyes para regular el uso de plásticos.

Desarrollo

  1. Los jóvenes redactan un proyecto de normas para reducir el uso de plásticos en su escuela o comunidad. 2. Debaten y votan sobre el proyecto.

Cierre

Los jóvenes obtienen una comprensión clara del proceso parlamentario para la elaboración de leyes.
