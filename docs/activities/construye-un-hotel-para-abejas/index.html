Construye Un Hotel Para Abejas

Actividad obligatoria para la sección A - ¿Qué es un polinizador? Construye un hotel para abejas en tu hogar, escuela o jardín comunitario. Monitorea el hotel para ver si atrae abejas y observa qué tipos de abejas lo visitan.

castores manada 1-2 horas

Materiales

  • Contenedor impermeable (cartón de leche, balde, tubería o caja vieja)
  • Bloques de madera
  • Pajitas o tallos naturales (bambú)

Construye un Hotel para Abejas

Resumen

Actividad obligatoria para la sección A: ¿Qué es un polinizador? Construye un hotel para abejas en tu hogar, escuela o jardín comunitario. Monitorea el hotel para ver si atrae abejas y observa qué tipos de abejas lo visitan.

Desarrollo

Consigue un contenedor impermeable, como un cartón de leche, un balde, una tubería o una caja vieja. 2. Haz agujeros en bloques de madera, con diámetros de 0.25, 0.3, 0.43, 0.45 o 0.6 cm. 3. Inserta los bloques de madera en el contenedor. Añade pajitas o tallos naturales, como bambú. 4. Cuelga tu hotel de abejas afuera, orientado hacia el sur o sureste. 5. Observa tu hotel de abejas para ver si atrae abejas.

Cierre

¿Qué tipos de abejas visitaron el hotel? ¿Cómo podemos mejorar el hábitat para los polinizadores en nuestra comunidad?
