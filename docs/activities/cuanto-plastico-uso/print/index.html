¿Cuánto Plástico uso?

Autoevaluación sobre uso de plástico.

Resumen

Vamos a pensar y descubrir cuánto plástico usamos, y después vamos a pensar cómo disminuir su uso.

Objetivos

  • Reflexionar sobre el consumo personal de plástico.
  • Identificar hábitos que generan residuos plásticos.
  • Generar compromisos para reducir el uso de plástico.

Preparación

  1. Divide el área de juego en 2, 3 o 4 sectores según la pregunta.
  2. Coloca carteles que indiquen a qué respuesta/afirmación corresponde cada sector.
  3. Los participantes se encuentran juntos en el centro del área de juego.

Desarrollo

Paso 1: Explicación

  1. El facilitador explica la actividad.
  2. Se lee la pregunta o afirmación en voz alta (para ayudar a los que puedan tener dificultades de lectura).

Paso 2: Movimiento

  1. Los participantes se mueven al sector que corresponde a su respuesta.
  2. Ejemplo: la afirmación "Yo uso pajitas de plástico" puede tener las opciones "Nunca", "Pocas veces", "Muchas veces", "Siempre".

Paso 3: Explicación y reflexión

  1. Entre preguntas, el facilitador explica el impacto de las acciones en el medio ambiente.
  2. Se repite para cada pregunta/afirmación.

Lista de Preguntas

Concientización general

  1. Quiero ayudar a disminuir el impacto humano en la naturaleza. (SI / NO / MÁS O MENOS)
  2. Sé cómo disminuir el impacto humano en la naturaleza. (SI / NO / MÁS O MENOS)
  3. Yo contamino. (MUCHO / POQUITO / NADA)
  4. Tiro basura en la calle. (SIEMPRE / CASI SIEMPRE / ALGUNAS VECES / NUNCA)

Conocimiento sobre plásticos

  1. Sé qué plásticos contaminan. (SI / NO / MÁS O MENOS)
  2. Uso pajitas de plástico para tomar gaseosas. (SIEMPRE / CASI SIEMPRE / ALGUNAS VECES / NUNCA)
  3. Tiro las botellas plásticas a la basura. (SIEMPRE / CASI SIEMPRE / ALGUNAS VECES / NUNCA)

Hábitos de reciclaje

  1. Separo la basura antes de tirarla. (SIEMPRE / CASI SIEMPRE / ALGUNAS VECES / NUNCA)
  2. Cuando hago las compras llevo una bolsa. (SIEMPRE / CASI SIEMPRE / ALGUNAS VECES / NUNCA)
  3. Tiro las pilas usadas a la basura. (SIEMPRE / CASI SIEMPRE / ALGUNAS VECES / NUNCA)

Ahorro de recursos

  1. Apago la luz al salir de la habitación. (SIEMPRE / CASI SIEMPRE / ALGUNAS VECES / NUNCA)
  2. Cierro bien la canilla cuando no la uso. (SIEMPRE / CASI SIEMPRE / ALGUNAS VECES / NUNCA)
  3. Cierro bien la canilla mientras me lavo los dientes. (SIEMPRE / CASI SIEMPRE / ALGUNAS VECES / NUNCA)

Conocimiento e impacto

  1. Sé qué impacto tiene la contaminación en los ecosistemas, en la salud de las personas y en las comunidades. (SI / NO / MÁS O MENOS)
  2. Participo de eventos que abordan la contaminación de los ecosistemas acuáticos y terrestres. (SI / NO / MÁS O MENOS)

Cierre

Discusión grupal

  • ¿Qué alternativas tenemos al uso de plástico?

Compromiso personal

  • Cada participante se compromete a reducir el uso (o eliminar) un elemento contaminante de su vida.
