El barquito chiquitito

Resumen

Actividad para crear una canción sobre el agua y compartirla con la comunidad.

Desarrollo

Elige una canción que te guste y reescribe las palabras para difundir un mensaje sobre el agua. Luego, con tus compañeros organiza un concierto grupal para presentar todas las diferentes canciones.

Cierre

Reflexiona sobre cómo el arte y la música pueden ser herramientas poderosas para crear conciencia sobre el agua.
