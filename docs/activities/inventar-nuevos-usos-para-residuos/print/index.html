Inventar nuevos usos para residuos

Inventa un nuevo uso para un residuo doméstico, como botellas plásticas o latas.

Desarrollo

Inventa un nuevo uso para un residuo doméstico (botellas plásticas, contenedores, latas, jarras, papel, cartulina, madera, fundas, cajas), el cual en caso contrario sería botado en la basura. Por ejemplo, puedes crear obras de arte o hacer juguetes para niños.

Cierre

Reflexiona sobre cómo la creatividad puede reducir el desperdicio.
