Sobre el proyecto

Fogata Recursos busca transformar fichas y materiales educativos en una plataforma abierta, navegable y fácil de utilizar desde cualquier dispositivo.

El objetivo es facilitar:

  • búsqueda de actividades
  • exploración por insignias
  • actividades relacionadas con ODS
  • recursos educativos scouts
  • materiales para dirigentes
