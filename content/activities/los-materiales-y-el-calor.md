# Los Materiales y el Calor

## Resumen
Con distintos experimentos, los scouts piensan por qué es importante aislar las casas con los materiales adecuados para ahorrar energía.

## Objetivos
- Analizar los materiales de las casas y su relación con el ambiente.
- Pensar en el impacto de usar materiales inadecuados.
- Mejorar costumbres para ahorrar energía.

## Desarrollo
1. Pongan cada lata chica dentro de una grande.
2. Rellenen el espacio entre las dos: una con papel de diario picado, otra con aserrín, otra con corcho molido y la última solo con aire. Rotulen cada una.
3. Hagan una tapa de cartón para cada lata, con un agujero para el termómetro.
4. Llenen las latas chicas con agua hirviendo hasta la misma altura y tápenlas.
5. Midan la temperatura cada cinco minutos y anótenla en una tabla.

| Aislante | 1.ª medida | 2.ª medida | 3.ª medida | 4.ª medida |
|---|---|---|---|---|
| Papel | | | | |
| Corcho | | | | |
| Aserrín | | | | |
| Aire | | | | |

6. Analicen: ¿qué lata perdió calor más rápido? ¿Cuál es el mejor aislante? ¿Qué tiene que ver con las paredes de una casa?

> **Nota de seguridad:** el agua hirviendo la maneja un dirigente. Las latas calientes se agarran con un trapo.

## Cierre
¿Qué aprendieron? ¿Lo pueden aplicar en casa? ¿Les hace pensar distinto sobre el ahorro de energía?
