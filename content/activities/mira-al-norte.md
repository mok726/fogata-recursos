# ¡Mirá al Norte!

## De qué se trata
Todos parados, separados. El que dirige muestra dónde queda el Norte del lugar (con brújula o con el sol). Después grita puntos cardinales: «¡Este!», «¡Sudoeste!». Todos saltan y quedan mirando para ese lado. El que se equivoca o tarda, pierde una vida.

## Cómo se juega
1. Párense separados, con lugar para girar.
2. El que dirige muestra dónde está el Norte. Con eso, entre todos ubican el Sur, el Este y el Oeste.
3. El que dirige grita un punto: «¡Oeste!». Todos saltan y quedan mirando hacia el Oeste.
4. El que mira para otro lado o es el último en girar, pierde una vida.
5. Con tres vidas perdidas, ayuda a controlar.
6. Para Scouts, sumen los puntos intermedios: Noreste, Sudoeste, Nornoroeste…

## Para cerrar
- ¿Cómo encontrarían el Norte si no tuvieran brújula?

## Notas para educadores
- Antes, ubicá el Norte real del lugar. En el hemisferio sur, al mediodía el sol está hacia el Norte.
- Complementa la Rosa de los 32 Rumbos y las fichas de orientación.
