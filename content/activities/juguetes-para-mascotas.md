# Juguetes para Mascotas

## Resumen
Las mascotas necesitan jugar para estar sanas y contentas, y para hacer cosas naturales como buscar, perseguir, morder o explorar. Con materiales reciclados, cada uno fabrica un juguete de «enriquecimiento» para su mascota o la de alguien conocido.

## Objetivos
- Conocer las cinco necesidades de bienestar de un animal.
- Entender por qué las mascotas necesitan jugar.
- Reutilizar materiales para algo útil.

## Las cinco necesidades de bienestar
1. **Un lugar adecuado** para vivir, con refugio y lugar para descansar.
2. **Comida y agua** adecuadas.
3. **Poder comportarse como su especie**: correr, olfatear, escarbar, trepar.
4. **Compañía** (o estar solo, según el animal).
5. **Cuidado de su salud**: protegerlo del dolor, las lesiones y las enfermedades.

## Preparación
1. Pedí con tiempo que traigan materiales reciclados limpios.
2. Revisá que todo sea seguro para el animal: sin piezas chicas que se puedan tragar, sin pegamentos tóxicos, sin hilos sueltos.

## Desarrollo
1. Preguntá quién tiene mascota y cuál es su juguete preferido.
2. ¿Por qué las mascotas necesitan juguetes? Presentá las cinco necesidades.
3. **A fabricar.** Cada uno elige un juguete según el animal:
   - **Botella con premios para un gato o perro chico:** botella plástica limpia con agujeros un poco más grandes que el alimento; al hacerla rodar, caen los premios.
   - **Túnel para hámster o cobayo:** tubos de cartón unidos con cinta de papel.
   - **Caja para romper para un perro:** una caja de cartón con papel arrugado y algunos premios escondidos adentro.
   - **Buscador de premios:** un cartón de huevos con premios en algunos huecos, tapados con papel.
4. Cada uno muestra su juguete y explica qué necesidad de la mascota ayuda a cumplir.

## Cierre
- ¿Qué necesidad de su mascota creen que está menos cubierta?
- ¿Qué otros juguetes se podrían hacer con materiales reciclados?
- ¿Podríamos hacer juguetes para un refugio de animales del barrio?

## Notas para el educador
- Recordá que los juguetes se usan **con supervisión**: si se rompen, se retiran.
- Como servicio, el grupo puede fabricar juguetes para una protectora o un refugio.
