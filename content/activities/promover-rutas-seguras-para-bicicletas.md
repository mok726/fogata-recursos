# Promover rutas seguras para bicicletas

## Resumen
Inicia una campaña para crear rutas seguras para bicicletas.

## Desarrollo
Empieza una campaña para la creación de rutas seguras (carriles) para andar en bicicleta en tu vecindario.

## Cierre
Reflexiona sobre cómo el transporte sostenible puede reducir el impacto ambiental.
