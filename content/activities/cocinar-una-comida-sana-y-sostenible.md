# Cocinar una comida sana y sostenible

## Resumen
Esta actividad es obligatoria para la categoría Nuestra Alimentación. Aprende a cocinar una comida sana y amigable con el medio ambiente.

## Desarrollo
Aprende a cocinar una comida sana y balanceada para tu familia. Trata de hacerla amigable con el medio ambiente, por ejemplo, usa productos locales frescos con poco embalaje o siémbralos tú mismo. Haz una lista de compras para evitar adquirir demasiados alimentos innecesarios, especialmente si no se pueden mantener por mucho tiempo (como frutas frescas, vegetales y carnes).

## Cierre
Reflexiona sobre cómo la elección de ingredientes locales y sostenibles puede reducir el impacto ambiental.
