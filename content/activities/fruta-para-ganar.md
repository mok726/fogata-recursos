# ¡Fruta para ganar!

## Resumen
Cambiar tus hábitos de snack puede ayudar a combatir el problema de los residuos plásticos. Muchos snacks vienen en empaques de plástico que se tiran. Comer fruta en lugar de papas fritas o golosinas no solo es bueno para tu salud, sino también para la salud del planeta.

## Preparación
1. Planifica tu snack de fruta la noche anterior para estar preparado.
2. Busca un envase reutilizable para llevar tu fruta.
3. Si quieres, prueba frutas nuevas o prepara ensaladas creativas.

## Desarrollo

### Parte I
Durante **tres semanas**, reemplaza tus snacks envasados en plástico por frutas frescas.

**Ideas para hacerlo divertido:**
- Prueba una fruta nueva cada semana
- Prepara una ensalada de frutas creativa
- Comparte tu experiencia con amigos
- Compara notas con otros participantes

### Parte II
Lleva un registro diario de tus snacks:

| Día | Snack habitual (con plástico) | Snack reemplazo (fruta) |
|-----|-------------------------------|------------------------|
| Lunes | | |
| Martes | | |
| Miércoles | | |
| Jueves | | |
| Viernes | | |
| Sábado | | |
| Domingo | | |

### Parte III
Al final de las tres semanas, reflexiona:
- ¿Fue más fácil o más difícil de lo que esperabas?
- ¿Qué frutas nuevas descubriste?
- ¿Notaste algún cambio en cómo te sentías?
- ¿Cuánto plástico ahorraste?

## Cierre
1. ¿Qué fue lo más difícil de este desafío?
2. ¿Qué fruta nueva fue tu favorita?
3. ¿Vas a seguir comiendo fruta como snack después de estas tres semanas?

## Texto original completo de la actividad

**English version:**

A.6 FRUIT FOR THE WIN

Switching our snacking habits can help tackle the plastic waste problem, too. Many snacks come in plastic packaging that gets thrown away. Snacking on fruit instead of crisps or sweets is not only good for your health but better for the planet's health, too. Plan your fruit snack the night before each day for three weeks, so you're prepared ahead of time. Make it fun by trying new fruit or making a creative fruit salad and packing it in a reusable container. Compare notes with friends. Who was able to avoid a plastic-packaged snack for three weeks?

**Versión en español:**

A.6 FRUTA PARA GANAR

Cambiar nuestros hábitos de snack también puede ayudar a combatir el problema de los residuos plásticos. Muchos snacks vienen en empaques de plástico que se tiran. Comer fruta en lugar de papas fritas o golosinas no solo es bueno para tu salud, sino también para la salud del planeta. Planifica tu snack de fruta la noche anterior cada día durante tres semanas, para estar preparado con anticipación. Hazlo divertido probando frutas nuevas o preparando una ensalada de frutas creativa y llevándola en un envase reutilizable. Comparte tus experiencias con amigos. ¿Quién pudo evitar un snack envasado en plástico durante tres semanas?
