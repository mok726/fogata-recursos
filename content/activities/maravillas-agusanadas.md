# Maravillas Agusanadas

## Resumen
Crea una lombricera para observar cómo las lombrices interactúan con el suelo.

## Desarrollo
Usa un contenedor transparente, tierra, arena y lombrices. Observa cómo las lombrices mueven el suelo entre las capas.

## Cierre
Discute cómo las lombrices ayudan a mantener el suelo saludable.
