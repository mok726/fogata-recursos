# Midiendo el clima

## Resumen
Los participantes aprenden cómo se mide el clima.

## Desarrollo
Los participantes investigan los instrumentos utilizados para medir el clima y cómo se usan los datos para predecir cambios. Luego, montan una estación meteorológica.

## Cierre
La estación meteorológica se usa para contribuir con mediciones locales.
